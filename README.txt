MYTHIA BATFORD — QUIZ CLUB

Cara menjalankan:
1. Ekstrak folder ini.
2. Buka index.html di browser modern (Chrome, Edge, Firefox, Safari).
3. Internet dibutuhkan untuk memuat font Google; fitur kuis dan foto tetap memakai file lokal.

Isi folder:
- index.html : struktur website
- style.css  : desain responsif ungu / dark-glam
- app.js     : 10 soal sejarah, navigasi, skor, dan pembahasan
- assets/    : empat gambar yang diberikan

Catatan: Background URL di halaman setup bersifat opsional. Seluruh empat gambar yang disediakan sudah dipakai di desain.
